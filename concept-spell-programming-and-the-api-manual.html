Spell programming and the API manual

Source: wiki.md

← Back to Concepts & Lore

Spells in Etheria can be designed through code-like interfaces with syntax, logic, restrictions, and triggers. Tasha found an API manual in the Temple of the Player that teaches the language. Spells have parameters like mana cost, cast time, cooldown, range, AOE radius, and directional constraints. Complex tradeoffs allow optimization — e.g., adding vocal triggers and body movements to reduce mana cost. Appears in: Couch Potato Chaos
