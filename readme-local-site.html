Couch Potato Chronicles local wiki site

This folder now includes a small local site generator for the markdown wiki files.

Quick start:

  1. Double-click start-wiki-site.bat

    • installs npm dependencies
    • builds the site into site/
    • starts a local server on http://127.0.0.1:8080

  2. Double-click watch-wiki-site.bat

    • watches *.md and site-assets/*
    • rebuilds the site when files change

Main commands:

  • npm run build → generate static HTML into site/
  • npm run watch → auto-regenerate on file changes
  • npm run serve → browse the generated site locally
  • npm run dev → build once, then serve

Generated pages:

  • wiki.md → site/index.html
  • other root markdown files each get their own page
  • timeline.md → site/timeline.html for the interactive chronology view

Timeline notes:

  • Timeline events currently live inside timeline.md as embedded JSON so the page stays self-contained.
  • Use category story-event for on-page plot developments and world-history for older lore / setting milestones.
  • Each event should include sort, when, era, title, summary, plus optional details, characters, locations, tags, and references.
  • The generated page supports search, event expansion, jump navigation by era, and category filters for story-event vs world-history entries.

Notes:

  • Edit the markdown files in the project root.
  • Re-run npm run build or keep npm run watch running.
  • Styling lives in site-assets/styles.css.
  • Client-side navigation filtering, Mermaid behavior, and timeline interactivity live in site-assets/site.js.
